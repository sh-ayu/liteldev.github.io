# 服务器

服务器页面用来安装当前工作区的服务器，也是服务器的控制台。读完这一页，你就能安装服务器、更改它的游戏或加载器版本、启动和停止它、查看它的输出、向它发送命令、让它在崩溃后自动重启，并且知道退出 lip 时服务器会怎样。

如果你还不熟悉按键和屏幕上的各个部分，请先读[界面导览](./tour.md)。

## 页面的组成

![服务器运行期间的服务器页面。编号标出状态行、输出区和输入行。](/screenshots/zh-Hans/server-02-running.svg)

1. **状态行**说明服务器是否在运行。它下面是**启动**或**停止**按钮、**自动重启**选项，以及**更改版本…**按钮。
2. **输出区**是服务器输出的内容。
3. **输入行**用来输入发给服务器的命令。只有服务器运行时才有这一行。

`Tab` 依次在各部分之间移动：按钮和选项、输出区、输入行。`←` 和 `→` 在按钮和选项之间移动。

## 服务器的每种状态

状态行显示的总是下面几种之一。

### 这里还没有服务器

没有游戏的文件夹里没有东西可运行。页面只有一个按钮。

![空文件夹的服务器页面。写着“这里还没有服务器。”，有一个“安装服务器…”按钮，下面一行是“在此工作区中安装游戏版本和加载器。”](/screenshots/zh-Hans/server-03-no-server.svg)

按 `Enter` 在这个工作区里安装服务器。每一步的说明见[安装服务器](#安装服务器)。

### 未运行

`○ 未运行`表示服务器没有运行，并且自 lip 启动以来没有运行过。输出区是空的。

![未运行的服务器的服务器页面。“启动”按钮处于高亮，输出区写着“还没有输出。”](/screenshots/zh-Hans/server-01-stopped.svg)

在**启动**上按 `Enter` 启动服务器。

### 运行中

按下“启动”后，在服务器的程序真正跑起来之前，状态是 `●` **正在启动**。通常只是一瞬间。lip 第一次需要为服务器准备系统时会久一些，例如 Windows 上的 Visual C++ 运行库，或者 Linux 和 macOS 上的 Wine。如果这一步失败，lip 会显示失败原因，状态回到 `○` **未运行**。

之后状态变成 `●` **运行中**。从服务器的程序跑起来的那一刻起就算运行中，哪怕它还在加载世界和模组。

![刚按下“启动”的服务器页面。状态是“运行中 · 00:00:00”，按钮变成“停止”，输出区有一行灰色文字，输入行出现了。](/screenshots/zh-Hans/server-05-just-started.svg)

1. `● 运行中`，后面是服务器已经运行的时间（时:分:秒）。
2. 按钮变成了**停止**。
3. 两端带横线的灰色行是 lip 自己写的，不是服务器的输出。
4. 输入行出现，焦点移到这里。

lip 的顶部一行也会显示 `● 运行中`，侧边栏的“服务器”后面多了一个 `●`。你可以去别的页面，服务器会继续运行。

服务器在输出里写出 `Server started.` 时，玩家就可以进入了。

::: info
如果服务器根本启动不了（比如缺少游戏文件），lip 会显示出错对话框，状态保持“未运行”。参见[出错的时候](./tour.md#出错的时候)。
:::

### 正在停止

让服务器停止之后，在它真正结束之前，状态是 `● 正在停止`。服务器通常需要几秒钟保存世界。

![按下 Ctrl+C 之后的服务器页面。状态是“正在停止”，输出区有一行灰色的“asking the server to stop”。](/screenshots/zh-Hans/server-08-stopping.svg)

1. lip 已请服务器停止，正在等它结束。
2. lip 向服务器发送了 `stop` 命令。

这期间“停止”按钮是灰色的：再按一次也不会有更多效果。

### 已退出，带退出码

服务器结束后，状态是 `○ 已退出，退出码`加一个数字。退出码 `0` 表示正常结束，其他数字表示出了问题。

![已结束的服务器的服务器页面。状态是“已退出，退出码 0”，按钮又变回“启动”，输出还在。](/screenshots/zh-Hans/server-09-exited.svg)

1. 服务器已不在运行。
2. **启动**可以再次启动它。
3. 输出会保留，可以查看服务器为什么结束。

### 正在重启

如果服务器以非 `0` 的退出码结束，不是你让它停的，并且**自动重启**已打开，lip 会在 5 秒后重新启动它。这期间状态是 `● 正在重启`，后面是服务器结束时的退出码。

![崩溃之后的服务器页面。状态是“正在重启 · 已退出，退出码 -1073741819”，自动重启已勾选，lip 用一行黄色文字说明 5 秒后重新启动服务器。](/screenshots/zh-Hans/server-11-restarting.svg)

1. lip 等待片刻，然后重新启动服务器。
2. 服务器是怎样结束的。
3. 自动重启已打开。

在 lip 等待期间按 `Ctrl+C` 或**停止**，服务器就不会被重新启动。

### 在此界面之外运行

服务器也可以在另一个终端里用普通的 `lip run` 命令启动。这时 lip 只知道服务器在运行，别的一概不知。

![服务器页面写着“在此界面之外运行”。按钮下方有一行“它由另一个 `lip run` 启动，请在那里停止。”](/screenshots/zh-Hans/server-10-elsewhere.svg)

1. 服务器在运行，但不是这个界面启动的。
2. **启动**在这里不起作用，也没有“停止”。
3. 请到启动它的地方去停止它。

这里没有输出区，也没有输入行，因为它们属于启动服务器的那个终端。其他和“服务器正在运行”有关的规则照样生效：在它停止之前不能改动模组。

## 安装服务器

**安装服务器…**在当前工作区里安装服务器：游戏，以及要装模组时的 LeviLamina。它用一个接一个的对话框问你几个问题，然后开始安装。按 `Esc` 返回上一步；在第一步按 `Esc` 则关闭对话框，什么都不会改变。

[主页](home.md)的第 2 步开始的也是这个过程。[开你的第一个服务器](https://levimc.org/zh-Hans/tutorials/server/first-server/)带你从头到尾走一遍；本节说明其中的每一个选择。

### 服务器放在哪里

服务器会装进当前工作区，也就是顶部一行显示的那个文件夹。

![没有服务器的文件夹的服务器页面。“安装服务器…”按钮被标出，下面一行写着“在此工作区中安装游戏版本和加载器。”](/screenshots/zh-Hans/new-server-01-where.svg)

1. 服务器会装进顶部一行显示的当前工作区。

要把服务器装在别的文件夹里，先在[工作区选择器](workspaces.md)里选中那个文件夹：已有的文件夹，或者用**添加文件夹…**新建的文件夹。然后回到这个页面，在**安装服务器…**上按 `Enter`。

### 第 1 步：游戏版本

lip 读取可以下载的游戏版本（需要一点时间）并列出来：先是正式版，从新到旧；然后是标着**预览版**的预览版本。

![“游戏版本”对话框列出 1.26.60 到 1.21.130。大多数行显示“LeviLamina ✓”，第一行标着“最新”。](/screenshots/zh-Hans/new-server-04-game-version.svg)

版本后面的一栏说明这个版本能不能装模组：

![同一个列表，选中的是显示“无 LeviLamina”的 1.26.30。下面一行写着“模组需要 LeviLamina，而此版本没有。”](/screenshots/zh-Hans/new-server-12-no-levilamina.svg)

1. **LeviLamina ✓**：有支持此版本的 LeviLamina。要装模组，就选这样的版本。
2. **无 LeviLamina**：没有为这个版本制作的 LeviLamina。这样的版本只能作为纯净服务器。
3. 对所选行的文字说明。

::: info 这一栏为什么重要
模组不能直接在游戏上运行。它们需要加载器 **LeviLamina**，而每个 LeviLamina 版本只对应一个游戏版本。最新的游戏版本不一定已经有对应的 LeviLamina。
:::

这一栏的内容来自 levimc.org 的模组目录。如果目录几秒钟内没有响应，列表就不显示这一栏；到加载器那一步仍然会告诉你哪些版本合适。

用 `↑` `↓` 选择版本，按 `Enter`。

### 第 2 步：构建（仅限 x64 的 Linux）

游戏有两种**构建**：Windows 服务器和 Linux 服务器。LeviLamina 及其模组需要 Windows 服务器。

只有在两种都能运行的地方（x64 处理器上的 Linux），并且所选版本两种构建都有时，lip 才会询问构建。其他情况下构建就是 `windows`，你不会看到这一步。在 Linux 上，只有其中一种构建的版本会在版本列表里注明：

![Linux 上的游戏版本列表。1.26.30 一行在“无 LeviLamina”后面标着“仅 windows”。](/screenshots/zh-Hans/new-server-16-linux-games.svg)

1. 没有 Linux 服务器的版本：选它时 lip 不会询问构建。

![“构建”对话框有 windows 和 linux 两行。选中的是 linux，下面一行写着“没有加载器；仅适用于 x64 的 Linux。”](/screenshots/zh-Hans/new-server-17-build.svg)

1. **windows**：Windows 服务器，lip 通过 Wine 运行它。只有它支持 LeviLamina 及其模组。
2. **linux**：Linux 服务器。它不需要 Wine，没有加载器，也不能运行模组。lip 会跳过加载器这一步。

关于 Wine 和 Linux 服务器，见 [Linux 与 macOS](../guides/linux_macos.md)。

### 第 3 步：加载器

lip 查找适合所选游戏版本的 LeviLamina 版本（可能需要一点时间）并列出来，从新到旧，最后是**不安装加载器**。

![“加载器”对话框列出标着“最新”的 LeviLamina 26.60.3 到 26.60.0，然后是“不安装加载器”。下面一行写着“让服务器可以运行模组。”](/screenshots/zh-Hans/new-server-05-loader.svg)

要装模组，就在第一行（最新的 LeviLamina）上按 `Enter`。

**不安装加载器**只安装游戏：一个不能运行模组的纯净服务器。

![同一个对话框，选中的是“不安装加载器”。下面一行写着“纯净服务器，不带模组。”](/screenshots/zh-Hans/new-server-14-no-loader.svg)

如果没有适合该游戏版本的 LeviLamina，这一步会说明，但不会让你无路可走：

![“加载器”对话框以“没有支持此游戏版本的 LeviLamina。”开头，有“不安装加载器”和“返回”两行。](/screenshots/zh-Hans/new-server-13-no-loader-fits.svg)

1. **不安装加载器**继续安装纯净服务器。
2. **返回**回到游戏版本列表，你可以改选带 **LeviLamina ✓** 的版本。按 `Esc` 也一样。

### 第 4 步：计划

lip 显示将要安装的内容，此时还没有安装任何东西。

![“安装服务器”对话框列出三行以“Dry run:”开头的内容，有“应用”和“取消”两个按钮。](/screenshots/zh-Hans/new-server-06-plan.svg)

这些行是命令的原话，是英文：这里是游戏、LeviLamina，以及 lip 会请你接受许可协议。

- **应用**开始安装。
- **取消**什么也不安装。页面上仍然是**安装服务器…**。

### 第 5 步：许可协议

游戏属于 Microsoft。在 lip 下载它之前，你必须接受《Minecraft 最终用户许可协议》和《Microsoft 隐私政策》。请到显示的两个网址阅读它们。

![“Minecraft EULA”对话框写出两份文件的名称和网址，有“接受”和“拒绝”两个按钮。](/screenshots/zh-Hans/new-server-07-eula.svg)

**接受**继续。**拒绝**不安装任何东西：

![同一个对话框，“拒绝”按钮被标出。](/screenshots/zh-Hans/new-server-15-eula-decline.svg)

工作区保持原样，页面上又是**安装服务器…**。

![拒绝之后的服务器页面：“这里还没有服务器。”和被标出的“安装服务器…”按钮。](/screenshots/zh-Hans/new-server-18-not-set-up.svg)

### 第 6 步：下载与结果

lip 下载并安装游戏和 LeviLamina。按 `Esc` 取消，已经做的部分会被撤销。

![“安装服务器”对话框显示两项下载，一项是 100%，另一项是 62%。](/screenshots/zh-Hans/new-server-08-progress.svg)

完成后，对话框列出安装了什么，最后一行是 **✓ 完成。** 按 `Enter`。

![“安装服务器”对话框列出已安装的两个包，最后是“完成。”和“确定”按钮。](/screenshots/zh-Hans/new-server-09-result.svg)

页面上现在是这个服务器，未运行，可以启动了。

![服务器页面，状态是“未运行”，有“启动”和“更改版本…”按钮，以及“自动重启”选项。“启动”被标出。](/screenshots/zh-Hans/new-server-10-workspace.svg)

1. **更改版本…**用其他版本重新安装服务器。

在**启动**上按 `Enter` 启动它，或者先去[市场](get_mods.md)。

::: details 用命令做同样的事
这个过程在当前工作区里按你的选择执行 [`lip setup`](../reference/commands/setup.md)，例如：

```shell
lip setup --game 1.26.60 --loader levilamina@26.60.3
```

选**不安装加载器**时是 `--no-loader`，选 Linux 服务器时是 `--build linux`。
:::

## 更改游戏或加载器的版本

要把服务器换到另一个游戏版本或另一个 LeviLamina 版本，就用**更改版本…**重新安装一次。步骤和[安装服务器](#安装服务器)相同，只是每一步都从服务器现有的版本开始。

1. 按两次 `→`，从**启动**移到**更改版本…**，后面会写着**更换游戏或加载器。** 按 `Enter`。

   ![未运行的服务器的服务器页面。“更改版本…”按钮被标出，后面一句是“更换游戏或加载器。”](/screenshots/zh-Hans/workspaces-14-change-button.svg)

2. 选择游戏版本。服务器现有的版本标着**已安装**，并且已被选中。

   ![“游戏版本”对话框，选中的 1.26.60 标着“最新”和“已安装”。](/screenshots/zh-Hans/workspaces-14-change-game-version.svg)

3. 选择加载器。对话框一开始选中服务器现有的 LeviLamina；没有加载器时选中**不安装加载器**。

   ![“加载器”对话框，选中的是最新版本下面一行的 LeviLamina 26.60.2。](/screenshots/zh-Hans/workspaces-15-change-loader.svg)

4. 阅读计划，选择**应用**。

   ![“安装服务器”对话框写着 lip 将卸载 LeviLamina 26.60.3 并安装 LeviLamina 26.60.2，有“应用”和“取消”两个按钮。](/screenshots/zh-Hans/workspaces-16-change-plan.svg)

   1. lip 将要移除和安装的内容（命令的原话）。
   2. 选择**应用**之前不会有任何更改。

服务器运行期间，**更改版本…**是灰色的，移到它上面会显示**请先停止服务器。** lip 不会在服务器运行时更换游戏。

::: warning 不适合新版本的模组
模组是为特定的 LeviLamina 版本制作的。如果某个已安装的模组没有适合你所选游戏或 LeviLamina 的版本，计划里会点名，并说明这次安装会卸载它。这时选择**应用**就会卸载这些模组。想保持原样，请选**取消**。
:::

如果选的就是服务器现有的版本，那就没有事情可做，计划里只有**关闭**：

![“安装服务器”对话框写着“不会有任何更改。”，只有“关闭”一个按钮。](/screenshots/zh-Hans/plan-02-no-changes.svg)

更换游戏版本会保留 `server.properties`、`allowlist.json`、`permissions.json` 和你的存档。旧游戏的其他文件会被删除，你复制到 `behavior_packs/` 或 `resource_packs/` 里的资源包也会随之删除；完整的清单见[更换游戏后保留什么](../reference/files.md#更换游戏后保留什么)。请先复制一份文件夹：旧版本的游戏可能打不开新版本保存的存档。

### 在别的系统上打开使用 Linux 构建的服务器

用 Linux 服务器安装的工作区只能在 x64 的 Linux 上运行。在其他系统上，lip 无法提供这种构建。它会在你做任何选择之前说明这一点，然后按 Windows 服务器继续：

![“游戏版本”对话框开头有两行：“此工作区使用 linux 构建，它无法在本系统上运行。安装时会改用 windows 构建。”](/screenshots/zh-Hans/workspaces-17-linux-build.svg)

1. 提示，在你做任何选择之前就显示。

随后计划的标题会写明构建：**改用 windows 构建**，并把 Linux 服务器列在要卸载的内容里：

![“改用 windows 构建”对话框列出 lip 将卸载 Linux 版游戏，并安装 Windows 版游戏和 LeviLamina。](/screenshots/zh-Hans/workspaces-18-switch-to-windows.svg)

## 启动和停止

要启动服务器，在**启动**上按 `Enter`。[主页](./home.md)的第 4 步做的是同一件事。

要停止服务器，有两种办法：

- 在服务器页面的任何位置按 `Ctrl+C`；或者
- 按 `Tab` 直到**停止**高亮，再按 `Enter`。

两者都是向服务器发送 `stop` 命令，让它保存世界后自己结束。lip 从不强行杀掉服务器。

::: warning
在其他页面上，`Ctrl+C` 是询问是否退出 lip。只有在服务器页面上、并且服务器正在运行时，它才是停止服务器。
:::

## 查看输出

焦点在输入行时，输出区会跟着服务器走：新的内容出现在底部。

想往回看，在输入行按 `Esc`。焦点移到输出区，它的标题变成亮色。

![输出区拥有焦点，并且已向上滚动。右边缘的标记表示上下还有内容。](/screenshots/zh-Hans/server-06-output-scrolled.svg)

1. 焦点在输出区。
2. `▲` 和 `▼` 表示上方和下方还有内容。
3. 用来滚动的按键。

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 滚动一行。 |
| `PgUp` `PgDn` | 滚动一屏。 |
| `Home` | 跳到第一行。 |
| `End` | 回到最后一行。 |

往回看的时候，即使服务器又输出了新内容，你正在看的那些行也不会移动。

要回到输入行，按 `End` 再按 `↓`，或者按 `Tab`。

## 向服务器发送命令

在输入行输入服务器的命令，按 `Enter` 发送。空输入行里灰色的 `list` 只是示例，不会被发送。

![输入行里是“say Welcome to Survival”。](/screenshots/zh-Hans/server-02-running.svg)

服务器的回应会出现在输出区。

lip 会记住你发送过的内容。在输入行按 `↑` 调出上一条，按 `↓` 往后翻。正在输入的内容不会丢：按 `↓` 翻过最后一条时，它会回来。

![输入行显示用上方向键调出的“list”。底部一行列出“↑↓ 历史”。](/screenshots/zh-Hans/server-07-history.svg)

这里输入的是 Minecraft 服务器的命令，比如 `list` 或 `say`，不是 lip 的命令。

### 离开输入行

焦点在输入行时，你输入的字母都会发给服务器，所以要靠 `Esc` 离开：

1. 按 `Esc`，从输入行到输出区。
2. 再按 `Esc`，到侧边栏。

`Tab` 也能离开输入行，直接到侧边栏。

## 自动重启

**自动重启**决定服务器崩溃后 lip 是否重新启动它。按 `→` 从按钮移到这个选项，它右边会出现一句说明。按 `Space` 切换。

![“自动重启”选项已勾选并处于高亮。右边是一句“崩溃后重新启动。”](/screenshots/zh-Hans/server-04-auto-restart.svg)

选项打开时：

- 服务器以非 `0` 的退出码结束，5 秒后会被重新启动。
- 你主动停止的服务器，或者以退出码 `0` 结束的服务器，不会被重新启动。
- 10 分钟内重启满 5 次之后，lip 不再重启，并在输出区里说明。这时请往上翻看输出，找出服务器反复失败的原因。

这个选项属于工作区，所以每个服务器各有各的设置。[设置](./settings.md)页面上显示的是同一个选项。

## 服务器运行时退出

服务器运行时退出 lip，询问里会说明服务器会怎样。

![询问“要退出 lip 吗？”，第二行是“运行中的服务器会继续运行。”](/screenshots/zh-Hans/server-12-quit-keeps-running.svg)

通常服务器会**继续运行**。lip 把服务器交给自己的后台程序（守护进程）来运行，界面关闭后它还在。你可以关掉终端。想回来时，在同一个文件夹打开终端并运行 `lip`：服务器页面会显示这个服务器和它最近的输出，你可以像之前一样输入命令、停止它。

只有一种少见的情况例外：lip 用不了守护进程、一切都由它自己运行时，询问里写的是另一句话：

![询问“要退出 lip 吗？”，第二行是“运行中的服务器会先停止。”](/screenshots/zh-Hans/server-13-quit-stops.svg)

这时如果选**退出**，lip 会请每个运行中的服务器停止，在它们结束的过程中显示服务器页面，等全部结束后再退出。

## 托管服务器

在这个页面上启动的服务器是托管服务器：它由 lip 的守护进程运行，不属于任何一个终端。所以退出 lip 后它还在运行，多个终端可以同时看到同一个服务器，每个工作区也可以同时各运行一个服务器。`lip run --managed` 命令启动和显示的是同一批服务器。[用命令行开服](https://levimc.org/zh-Hans/tutorials/server/command-line/)对此有详细说明，也讲了不用界面时如何停止它。
