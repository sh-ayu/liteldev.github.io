# 主页

主页是 lip 启动后显示的第一个页面。读完这一页，你就能看懂它对文件夹的概览，用它的步骤把服务器跑起来，并且知道 lip 连不上 GitHub 时该怎么回答它的询问。

如果你还不熟悉按键和屏幕上的各个部分，请先读[界面导览](./tour.md)。

## 概览

页面的上半部分说明工作区（lip 正在操作的文件夹）里现在有什么。

![一个有服务器、还没有模组的文件夹的主页。编号标出概览、已完成的步骤、高亮的步骤和步骤下方的一句话。](/screenshots/zh-Hans/home-03-server-created.svg)

1. 概览。各行的含义见下表。
2. 带 `✓` 的步骤已经完成。
3. 高亮的步骤是接下来该做的一步。
4. 一句话说明在高亮的步骤上按 `Enter` 会做什么。

| 行 | 显示 |
| --- | --- |
| 工作区 | 文件夹的路径。路径太长时会截掉开头，保留末尾。 |
| 游戏 | 文件夹里 Minecraft 服务器的版本，或者“未安装”。 |
| 加载器 | LeviLamina 及其版本，或者“无”。模组需要加载器。 |
| 模组 | 你安装的模组数量。只因为其他模组需要才装上的模组不算在内，游戏和加载器也不算。 |
| 服务器 | “未运行”，或者 `●` 加“运行中”。从按下启动到服务器的程序跑起来之前显示“正在启动”。刚让服务器停止时显示“正在停止”；lip 等待重新启动崩溃的服务器时显示“正在重启”。 |

页面刚打开的一瞬间，各行会显示 `…`，表示 lip 正在读取文件夹。

## 下一步

概览下方的**下一步**列出从文件夹到服务器跑起来的四个步骤。lip 会高亮第一个还没完成的步骤，所以多数时候你只需要按 `Enter`。

用 `↑` 和 `↓` 在步骤之间移动，按 `Enter` 打开高亮的步骤。

| 步骤 | 何时算完成 | 按 `Enter` |
| --- | --- | --- |
| 1 选择工作区 | 始终完成：总有一个当前工作区。 | 打开[工作区选择器](./workspaces.md)，选择或添加别的文件夹。 |
| 2 安装服务器 | 文件夹里有了游戏。 | 打开[服务器](./server.md)页面并开始[安装服务器](./server.md#安装服务器)。 |
| 3 安装模组 | 你至少安装了一个模组。 | 打开[市场](./get_mods.md)页面。 |
| 4 启动服务器 | 服务器正在运行。 | 打开[服务器](./server.md)页面并启动服务器。 |

### 还没有安装服务器

在没有服务器的文件夹里，只有第 1 步打勾，高亮的是第 2 步。

![空文件夹的主页。只有“选择工作区”打勾，“安装服务器”处于高亮。下方的一句话是“为此工作区选择游戏版本和加载器。”](/screenshots/zh-Hans/home-01-empty.svg)

1. 当前显示的页面。左侧的侧边栏列出所有页面。
2. 下一步：按 `Enter` 开始。
3. 当前可用的按键。

按 `Enter` 在这个文件夹里安装服务器。之后的过程见[开你的第一个服务器](https://levimc.org/zh-Hans/tutorials/server/first-server/)。如果服务器要放在别的文件夹里，先用第 1 步选中那个文件夹。

### 服务器已安装

文件夹里有了游戏之后，第 1、2 步打勾，高亮移到第 3 步。本页开头的图就是这个状态。按 `Enter` 浏览 levimc.org 上的模组。

第 3 步可以跳过。不装模组的服务器也能运行：按 `↓` 再按 `Enter` 就可以直接启动。

### 模组已安装

至少安装了一个模组之后，第 1 到 3 步打勾，高亮移到第 4 步。

![装了四个模组的服务器的主页。第 1 到 3 步已打勾，“启动服务器”处于高亮。](/screenshots/zh-Hans/home-04-mods-installed.svg)

按 `Enter`，lip 会打开服务器页面并启动服务器。

### 服务器正在运行

服务器运行期间，四个步骤全部打勾。顶部一行和概览都显示“运行中”。

![服务器运行期间的主页。四个步骤全部打勾，顶部一行显示“运行中”。](/screenshots/zh-Hans/home-02-all-done.svg)

这时在第 4 步上按 `Enter` 只会打开服务器页面，不会再启动什么；步骤下方的一句话是**运行中。按 Enter 打开控制台。**

### 已完成的步骤还能再打开

打勾不代表锁定。在第 1 步上按 `Enter` 总是打开工作区选择器，在第 3 步上按 `Enter` 总是打开“市场”，可以继续装别的模组。在已打勾的第 2 步上按 `Enter` 会重新开始安装，用来更改服务器的游戏或加载器版本。

![第 2 步已打勾并处于高亮。下方的一句话是“已完成。按 Enter 更改游戏或加载器版本。”](/screenshots/zh-Hans/home-05-step-done.svg)

### 没有服务器时启动

没有服务器的文件夹里没有东西可启动。这时在第 4 步上按 `Enter`，lip 会在底部一行的右侧显示“请先安装服务器。”，并把高亮移回第 2 步。

![空文件夹的主页，在第 4 步上按 Enter 之后。底部一行显示“请先安装服务器。”，第 2 步重新高亮。](/screenshots/zh-Hans/home-06-need-server.svg)

1. 提示消息。几秒后自动消失。
2. 高亮回到了安装服务器的那一步。

## 连不上 GitHub 时

LeviLamina 和大多数模组都是从 GitHub 下载的。每次启动界面，lip 都会在后台检查能否连上 GitHub。它最多等 10 秒，这期间你可以照常使用界面。

检查失败时，lip 会询问该如何连接 GitHub。它会等到没有其他对话框打开时才问，不会打断你正在做的事。

![“无法连接 GitHub”对话框。它说明连接失败的原因，询问“lip 应如何连接 GitHub？”，并给出“使用代理”“直接连接”和“以后再说”三个回答。](/screenshots/zh-Hans/home-07-github.svg)

1. lip 连不上 GitHub 的原因。
2. 三种回答，默认高亮第一个。
3. 关于高亮回答的一句话说明。

用 `↑` 和 `↓` 选择，按 `Enter` 确认。在你回答之前，什么都不会改。

::: info
只要你在[设置](./settings.md)页面设置过 GitHub 代理，或者选择过直接连接，lip 就不会再做这项检查。
:::

### 使用代理

如果你所在的网络访问 GitHub 很慢或被屏蔽，而且你知道一个 GitHub 代理的网址，就选这一项。lip 不会推荐任何代理。

lip 会打开[设置](./settings.md)页面并询问代理网址。

![设置页面上的“GitHub 代理”对话框，“代理网址”文本框里是用户输入的网址。](/screenshots/zh-Hans/home-11-github-proxy.svg)

输入网址后按 `Enter`。lip 会先测试这个代理，可用就保存。不可用时，你可以换一个网址，也可以坚持保存这一个。完整的说明见设置页面。

在这个对话框里按 `Esc` 不会保存任何东西，lip 下次启动时会再问。

### 直接连接

如果你平时能正常访问 GitHub，这次检查失败只是别的原因（比如网络刚好断了一下），就选这一项。

![“直接连接”处于高亮。下方的一句话是“保持直接连接，不再询问。”](/screenshots/zh-Hans/home-08-github-direct.svg)

lip 会记下使用直接连接，并在底部一行告诉你。以后它不再检查，也不再询问。

![主页。底部一行的右侧是消息“已设为直接连接。”](/screenshots/zh-Hans/home-10-github-direct-saved.svg)

以后想改，到[设置](./settings.md)页面设置或清除 GitHub 代理即可。

### 以后再说

暂时不想决定，就选这一项。按 `Esc` 效果相同。

![“以后再说”处于高亮。下方的一句话是“不做更改，下次启动时再问。”](/screenshots/zh-Hans/home-09-github-later.svg)

lip 什么都不改。下次启动界面时它会再检查一次，如果还是失败就再问一次。

::: warning
在连上 GitHub 之前，安装带 LeviLamina 的服务器和安装大多数模组都会失败，出错对话框会说明 lip 无法连接服务器。参见[故障排除](../guides/troubleshooting.md)。
:::
